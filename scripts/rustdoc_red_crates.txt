# This is a debt ledger, not a config knob. `scripts/rustdoc_ratchet.sh` fails
# when a crate NOT listed here goes red (a regression) and equally when a crate
# listed here comes back clean (the ledger is stale). So:
#
#   * Never add a line to silence a new failure. A crate that used to document
#     is a regression, and adding it here converts a caught defect into
#     permanent debt.
#   * When you fix a crate, DELETE its line in the same commit. Until you do,
#     the crate is not gated and a later regression in it passes unnoticed.
#

# Python interpreter), exactly as cross-check.yml excludes it from both compile
# jobs. Absent from the scan is not the same as clean, and it is not tracked
